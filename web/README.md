# Gelecekteki Web Sitesi

Bu klasör ileride araştırma içeriğinin web arayüzüne dönüştürülmesi için ayrılmıştır.

## Hedef

İçerik dosyalarını ve `data/` altındaki yapısal veriyi okuyarak aşağıdaki özellikleri sunan statik veya hafif bir web sitesi oluşturmak:

- Çeşit kataloğu
- Yaprak / meyve / çekirdek karşılaştırması
- Saha gözlemleri
- Harita görünümü
- Kaynakça
- Türkçe / Yunanca / İngilizce dil desteği

## Dil stratejisi

İlk sürüm Türkçe olacaktır. İçerik mimarisi şu locale kodlarını kullanacak:

- `tr` — Türkçe
- `el` — Ελληνικά
- `en` — English

Web uygulaması seçilmeden önce araştırma verisinin stabil hale gelmesi tercih edilir.
