# Gazimağusa — Önder AVM yanı otopark

Bu klasör, saha kataloğu **MAG-ONDER-001** için görsel varlıkların hedef dizinidir.

## Fotoğraf seti

Bu oturumda aynı ağaç için şu fotoğraf grupları toplandı:

- ağaç ve taç genel görünümü
- yaprak ve dal yakın planları
- farklı dallarda yeşil meyve kümeleri
- meyve yakın planı
- meyve eti / sululuk gözlemi
- çekirdeğin temizlenme aşamaları
- çekirdek yan görünümü
- cetvel üzerinde çekirdek ölçüm fotoğrafı
- meyve ve çekirdeğin yan yana görünümü

## Dosyalama standardı

Yeni saha fotoğraflarında aşağıdaki isimleme kullanılacaktır:

```text
MAG-ONDER-001-tree-01.jpg
MAG-ONDER-001-leaf-01.jpg
MAG-ONDER-001-fruit-01.jpg
MAG-ONDER-001-fruit-02.jpg
MAG-ONDER-001-stone-01.jpg
MAG-ONDER-001-stone-ruler-01.jpg
MAG-ONDER-001-fruit-stone-01.jpg
```

Orijinal çekimlerin binary dosyaları sohbet oturumunda mevcut; GitHub bağlantısının mevcut metin-yazma işlemi binary yüklemeyi desteklemediği için bu klasörde şimdilik katalog/manifest bilgisi tutulmaktadır. Web sayfası ve saha kaydı bu lokasyon kodunu kullanır.
