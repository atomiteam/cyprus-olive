# Katalog Görselleri

Bu klasör yaprak, meyve ve çekirdek karşılaştırma katalogları için ayrılmıştır.

Planlanan ilk görsel:

- `zeytin-cesitleri-karsilastirma-katalogu.jpg`

Katalog görselleri **temsilî karşılaştırma** içindir; tek başına çeşit doğrulaması olarak kullanılmamalıdır. Her görselin yanında kaynak ve sürüm bilgisi tutulacaktır.
